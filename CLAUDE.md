# Project Instructions

## Brand Context

When producing content, copy, SEO, emails, or strategy for tchop.io, load the relevant context files:

| File | Contents |
|------|----------|
| `.claude/context/brand.md` | Product positioning, competitors, pricing |
| `.claude/context/icp-context.md` | Buyer personas, ICP segments |
| `.claude/context/tone-and-voice.md` | Writing style, banned phrases, structural patterns to avoid, EN writing samples |
| `.claude/context/tone-and-voice-de.md` | German-specific tone rules, DE writing samples |
| `.claude/context/messaging.md` | Approved phrases and CTAs by ICP (EN) |
| `.claude/context/messaging-de.md` | Approved phrases and CTAs by ICP (DE) |
| `.claude/context/sales-objections.md` | Objection handling by segment |
| `.claude/context/tech-stack.md` | Infrastructure, security claims |
| `.claude/context/product-architecture.md` | Domain model, card types, roles, permissions |
| `.claude/context/design-system.md` | Colors, typography, logo, illustration style |
| `.claude/context/content-inventory.md` | Existing English pages and URLs |
| `.claude/context/content-inventory-de.md` | Existing German pages and URLs (generated by `.claude/skills/blog-input-create/scripts/build-de-inventory.py`) |

## Skills

Curated skill set for tchop marketing and content work. Pruned from 57 to 17 skills in April 2026 to reduce context bloat. Removed skills are recoverable from git history if needed.

### Blog pipeline (primary)

| Skill | Purpose |
|---|---|
| `blog-input-create` | Turn any URL + hook into two published blog posts (EN + DE), repurposed into social assets. 13-phase orchestrator. |
| `content-repurposing-engine` | Convert long-form content into LinkedIn / X thread / Bluesky / video script / newsletter / TL;DR formats. |
| `tone-style-enforcer` | Brand voice guard. Single-artifact and cross-artifact-consistency modes. Loads tone-and-voice.md / tone-and-voice-de.md. |
| `content` | General-purpose tchop content writer. Loads brand + tone + messaging context. |
| `stop-slop` | Removes generic AI writing patterns. Complements tone-style-enforcer (which handles tchop-specific rules). |
| `last30days` | Research skill. Pulls last-30-day signals from Reddit, X, YouTube, HN, Polymarket, web. |
